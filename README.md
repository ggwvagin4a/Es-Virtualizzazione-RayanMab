# Es-Virtualizzazione-RayanMab
Esercitazione su virtualizzazione con VirtualBox e versionamento del codice con GitHub. Include presentazione Prezi sui concetti di ipervisore Tipo 2 e flusso di lavoro Git.

Questa repository raccoglie il materiale relativo all'esercitazione su **virtualizzazione** e **versionamento del codice**.

Il progetto esplora:
- Il concetto di **ipervisore** e il funzionamento di **VirtualBox** (Tipo 2 - Hosted)
- I vantaggi dell'utilizzo delle macchine virtuali (isolamento, test, risparmio hardware)
- Il flusso di lavoro con **GitHub**: backup, versionamento tramite commit e uso come portfolio digitale
